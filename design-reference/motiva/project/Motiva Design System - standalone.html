MOTIVA DESIGN SYSTEM · v1.0

The foundation, not the wallpaper.

This turns the Visual Manifesto's philosophy into tokens, materials and components — the shared vocabulary every future Motiva screen is built from. Where the manifesto was right, we specify it precisely. Where it was vague, we make a call here.

ONE REFINEMENT TO THE MANIFESTO

The manifesto named two brand hues plus an "attention" concept but left it loose. Locking it now: three semantic hues total, no more — violet (focus/action), teal (progress/done), rose (attention/blocking). Everything else, forever, is neutral ink on paper. This is the single rule most responsible for keeping Motiva from drifting back into admin-dashboard territory as the product grows.

Rules for using color: color appears on at most 2–3 elements per screen. Violet marks the thing to act on (primary button, active nav, the signature glow). Teal marks forward motion (completed steps, approvals, progress fill). Rose is reserved — it only ever means "this is blocking you," never a generic warning. If a screen needs a fourth color to communicate status, it's not a color problem, it's a wording problem: say it in words.

Hierarchy: ink carries all reading. Muted ink is metadata. Color is never used for hierarchy or decoration — only for meaning that the student must act on.

One family throughout: Assistant. Hierarchy is built from the five roles above plus spacing — never from arbitrary in-between sizes. Line length for body text stays under ~70 characters; reading rhythm comes from generous line-height (1.6+) and paragraph spacing, not letter tricks.

Spacing & Radius

4px base unit → 4·8·12·16·24·32·48·64·96. Rows use 12–16px internal padding; modules use 24–32px; page sections separate by 64–96px. Vertical rhythm > horizontal density — when in doubt, add vertical space, not another border.

Shadows are always cool-tinted (violet-black, never pure gray) and low-opacity. Elevation has three steps only — resting, module, overlay. Nothing sits above "overlay" — no double-stacked shadows.

02 · MATERIALS

Five surfaces, each with a job

Ambient

Threshold-only wash. Appears at login, session start, milestone/approval moments. Never behind persistent chrome.

Paper

The default background of every workspace page. Matte, opaque, warm off-white. No blur.

Elevated paper

White + shadow-md. For the one or two modules per page that deserve isolation (milestone tracker, a highlighted action).

Floating surface

Modals, drawers, menus. Highest elevation in the system — used sparingly, always dismissible.

Glass

Rationed to one instance per screen, max: the sidebar/nav strip when it sits over an ambient threshold. Never for content surfaces — glass over text hurts legibility.

04 · MOTION

Confident, slow, never bouncy

Timing: 120ms micro (hover), 200ms interaction (open/close a row), 320ms module transitions, 480–600ms ambient fades.
Easing: ease-out for anything entering, ease-in-out for ambient. No spring, no overshoot, no bounce — ever.
Hover: a 2–4% lift in ink weight or a 1px shadow increase. Never a color swap or scale-up.
Focus: 2px violet ring, offset 2px. Keyboard-visible always, not just on click.
Loading: a quiet pulse on the paper surface, not a spinner. The product waits calmly, it doesn't spin anxiously.
Success: a contained 400ms ambient bloom + signature glow on the element, then settle. Rare, so it stays meaningful.

05 · ICONOGRAPHY

One outline family, one job each

1.5px stroke, rounded caps and joins, drawn on a 24px grid, single weight throughout. The signature glow dot is the only filled mark in the system — that contrast is what makes it read as special. Icons appear next to nav destinations and primary actions; they disappear inside dense metadata rows (a due date doesn't need a calendar glyph next to it — the word is enough). When in doubt, cut the icon before adding a second color to it.

06 · LAYOUT SYSTEM

Same skeleton, different rhythm

Sidebar: fixed 248px, paper material, glass only when a threshold ambient is behind it. Workspace content caps at ~1040px so reading lines stay short. Header is a single slim row — greeting/title + 1–2 icon actions, never a second toolbar stacked under it.

Dashboard

Widest rhythm: one milestone card + rows beneath. Ambient greeting at top. Feels like opening a daily planner.

My Tasks

Densest rhythm: grouped rows by status, tightest spacing scale, no ambient beyond the header. Feels like a productivity tool.

Requests

Conversational rhythm: taller rows with more breathing room, since each is a small exchange, not a checklist item.

07 · PRODUCT RULES

The rulebook

  1. Ambient marks moments, never locations.
  2. One workspace per page — not a grid of competing panels.
  3. Rows are the default; cards are earned.
  4. Three semantic hues, total, forever: violet, teal, rose.
  5. Status is a word + the signature glow — never a colored badge rainbow.
  6. One icon family, outlined, one weight. No emoji, anywhere.
  7. No motion bounces, springs, or celebratory bursts.
  8. One glass surface per screen, maximum — never on a content/text surface.
  9. Every screen leads with "what needs you," not "what's your status."
  10. Dashboard, Tasks, Requests share materials but tune rhythm to their job.
  11. When unsure, remove a color or a container before adding one.

Motiva Design Cheat Sheet

COLOR

Violet = act on this. Teal = moving forward. Rose = blocking. Nothing else gets color. Paper #FAF9F7, ink #1A1820.

TYPE

Assistant only. Moment / Title / Heading / Body / Meta / Label — 6 roles, no in-betweens.

SPACING & RADIUS

4px base scale. Radius: 10 / 16 / 22 / 32.

MATERIALS

Ambient (thresholds only) → Paper (default) → Elevated paper (1–2 modules) → Floating (overlays) → Glass (rare, chrome only).

COMPONENTS

Rows by default, cards are earned. Status = word + glow dot, never a badge. One outlined icon family, no emoji.

MOTION & SIGNATURE

200–600ms, ease-out/in-out, never bouncy. The signature glow dot marks whatever needs attention right now — everywhere else stays quiet.
