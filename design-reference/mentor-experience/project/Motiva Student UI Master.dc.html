MOTIVA STUDENT UI · VISUAL SOURCE OF TRUTH

One page, every pattern.

This is not a screen — it's the reference every Student screen should be checked against, and the foundation the Mentor interface will reuse. Where today's screens disagree, this page shows the version that best follows the Visual Identity: five surfaces each with a job, rows before cards, status as word + glow — never a badge rainbow.

01 · PAGE STRUCTURE & NAVIGATION

One skeleton, shared by every Student screen

Fixed 248px RTL sidebar (paper, hairline border) · slim page header living inside the ambient zone · content capped near 1040px so reading lines stay short · one notification bell, one project/team identity line. Dashboard, Tasks and Requests all build on exactly this shell — only the content below the header changes rhythm.

02 · AMBIENT & HERO SURFACES

Five surfaces, each with a job

Ambient marks a moment, never a location — it lives at the top of a page load, behind the header, then the page goes quiet. Never behind the sidebar. Everything below the ambient zone is plain paper (#FAF9F7) or white — not a floating card.

When to use which: ambient → session start / milestone or approval moment, top of page only. White / paper → almost everything else. Elevated paper → the one module per page that deserves isolation (a milestone tracker, one highlighted action). Glass → the sidebar/nav strip over an ambient threshold, never over body text.

04 · CARDS

Same skeleton, different purpose — not six card designs

One Motiva card architecture, three foundations. Every card shares: 20px radius, 22px padding, a leading 36px icon/avatar slot, title (15px/700) → meta (12.5px/#8B8698) → trailing status (dot+word). Variation comes from purpose, not from a new container style. Elevation is a single rule — a card is either a hairline or a shadow, never both.

05 · STATUS SYSTEM

One rule: dot + word. Never a badge rainbow.

Three semantic hues, total, forever. Violet = something is happening / current step. Teal = resolved, positive outcome. Rose = blocking, needs the student now. Anything the student is calmly waiting on gets a neutral dot — waiting is not a warning.

Confident, slow, never bouncy

12 · ACCORDIONS / EXPANDABLE CONTENT

One interaction language, reused everywhere

Chevron rotates 180° on open, 200ms ease-out. Row background gets a faint tint on hover. Content reveals via height + opacity transition, never a hard cut. Used identically for milestone tasks (section 9) and requests (section 10) above.
