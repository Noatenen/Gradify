ACCESSIBILITY SPECIFICATION

Text contrast

Primary 17.6:1 · Secondary 9.2:1 · Metadata 5.3:1 (min). Nothing that must be read drops below 4.5:1; large decorative text only may sit at 3:1+.

Pulse sizing

Core 7–8px. Default halo ≤2px, barely visible. Attention-only halo up to 3px + soft outer ring. Never a filled background disc.

Ambient intensity

Hero/Focus/Compact per A2, always anchored at a corner. Text zone stays within ~10% opacity of the base surface.

Safe text zone

Title, body, metadata and buttons never sit inside the strongest 40% of any gradient's concentration.

Semantic color use

Dot = vivid brand hue. Label = darkened accessible hue. Status is always dot + word, never color alone.

Emphasis budget

Max two per component: Ambient+Pulse, Ambient+button, or Pulse+label. Never stack all mechanisms at once.

Motiva should still feel atmospheric from a distance — but every word, date and button reads clearly the moment a student starts working.
